# はじめに
ここではdcの基本的な考え方であるスタックについて勉強していきましょう。
スタックというのはデータを上に積んでいって、それを上から取り扱うような構造をいいます。
1ページ目ではスタックについて触れずに進めていましたが、スタックを理解するために、いったん1ページ目の内容は忘れて読み進めてください。
# スタックの扱い方

```
2 13
```
![b02_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc2/b02_01.png)

数字を書くとその数字がスタックに積まれます。数字同士はスペースで区切ってください。
***

|入力|5 3<br> 9|
|:-:|:-|

```
??
```

![b02_02.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc2/b02_02.png)

「?」で数字を読み込むと前から順にスタックに積まれていきます。
「?」は一行だけ読み込みます。


***

```
6 8pn
```

|出力|8<br>8|
|:-:|:-|

![b02_03.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc2/b02_03.png)
「p」は一番上の値に改行を付けて出力します。
「n」は一番上の値を取り出し、改行を付けずに出力します。
# 計算のコマンド
1ページ目では計算に「+」「-」「*」「/」「%」「^」が使えると紹介しましたが、実際にスタックがどうなっているかを見ていきましょう。この6つは2つの値を取り出し、その計算結果をスタックに積むという操作をしています。

```
6 8+
```

![b02_04.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc2/b02_04.png)
$6 + 8$を計算します。

***

```
8 2-
```

![b02_05.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc2/b02_05.png)
$8 - 2$を計算します。

***

```
3 4*
```

![b02_06.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc2/b02_06.png)
$3 \times 4$を計算します。

***

```
11 4/
```

![b02_07.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc2/b02_07.png)
$11 \div 4$を計算します。
整数の割り算は切り捨てて整数が答えになる。

***

```
11 4%
```

![b02_08.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc2/b02_08.png)
$11 \div 4$の余りを計算します。

***

```
3 2^
```

![b02_09.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc2/b02_09.png)
$3^2$を計算します。

# 他の演算子
「~」は割り算をして商と余りをスタックに積みます。

[ABC023](https://atcoder.jp/contests/abc023/tasks/abc023_a)

|入力|23|
|:-:|:-|

```
?A~+p
```

|出力|5|
|:-:|:-|

![a023_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc2/a023_01.png)

この問題のためにあるようなコマンドですね。

***
「|」はべき剰余を計算します。

```
5 2 7|
```

![b02_10.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc2/b02_10.png)

$5^2$を$7$で割った余りを計算しています。
***
「v」はルートを計算します。桁数には気をつけるようにしましょう。

```
Bv
```

![b02_11.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc2/b02_11.png)

$\sqrt{11}$を計算しています。
数字が負のときは、なにも積まないので、ただ一番上のデータが消えます。
