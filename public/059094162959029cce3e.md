# はじめに
ここではdcの基本的な考え方であるスタックについて勉強していきましょう。
スタックというのはデータを上に積んでいって、それを上から取り扱うような構造をいいます。
1ページ目ではスタックについて触れずに進めていましたが、スタックを理解するために、いったん1ページ目の内容は忘れて読み進めてください。
# スタックの扱い方

```
2 13
```
![b02_01.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1327735/581f1d77-b7d7-2bcc-c4f3-ee5a46443c6a.png)

数字を書くとその数字がスタックに積まれます。数字同士はスペースで区切ってください。
***

|入力|5 3<br> 9|
|:-:|:-|

```
??
```

![b02_02.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1327735/c527ea92-e209-5405-545c-74b9f98dd207.png)

「?」で数字を読み込むと前から順にスタックに積まれていきます。
「?」は一行だけ読み込みます。


***

```
6 8pn
```

|出力|8<br>8|
|:-:|:-|

![b02_03.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1327735/0ed1efb6-1f89-7ffd-e727-6efbf8be2383.png)
「p」は一番上の値に改行を付けて出力します。
「n」は一番上の値を取り出し、改行を付けずに出力します。
# 計算のコマンド
1ページ目では計算に「+」「-」「*」「/」「%」「^」が使えると紹介しましたが、実際にスタックがどうなっているかを見ていきましょう。この6つは2つの値を取り出し、その計算結果をスタックに積むという操作をしています。

```
6 8+
```

#他の演算子
「~」は割り算をして商と余りをスタックに積みます。

[ABC023](https://atcoder.jp/contests/abc023/tasks/abc023_a)

|入力|23|
|:-:|:-|

```
?A~+p
```

|出力|5|
|:-:|:-|

![a023_01.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1327735/30c2baa7-3eed-32e9-8dff-13d8a7548d27.png)

この問題のためにあるようなコマンドですね。

***
「|」はべき剰余を計算します。

```
5 2 7|
```

![b02_10.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1327735/1f1439de-b9a0-7d39-3343-e223726a5f19.png)

$5^2$を$7$で割った余りを計算しています。
***
「v」はルートを計算します。桁数には気をつけるようにしましょう。

```
Bv
```

![b02_11.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/1327735/fad564f8-17be-6c1c-b101-b48d2a4c88e2.png)

$\sqrt{11}$を計算しています。
数字が負のときは、なにも積まないので、ただ一番上のデータが消えます。
