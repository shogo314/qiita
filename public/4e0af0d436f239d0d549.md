```
  (let [ am (Maybe.unsafe-from a)
```

```
split(" ")|map(tonumber)as$tmp|($tmp[0]-1)/$tmp[1]|floor
```

# なでしこ
```
tmp=「」と尋ねて「 」で区切る。
Aは「{tmp[0]}n」をJS実行。
Tは「{tmp[1]}n」をJS実行。
(A-1n)/Tを表示。
```

# プロデル
```
【tmp：整数の配列】は、コンソールから受け取ったものを「 」で区切ったもの。
【A：整数】は、tmp(1)。
【T：整数】は、tmp(2)。
(A-1)\Tを表示。
```
