# はじめに
ここではd,r,s等のコマンドについて解説します。

# f
これはスタックの内容を上から順に全て出力します。
自分のコードが正しく動いているかの確認などに使えます。

```
7 2 5f
```

|出力|7<br>2<br>5|
|:-:|:-|

![b03_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc3/b03_01.png)

# d
一番上のデータを複製して一番上に積みます。

```
2d
```
![b03_02.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc3/b03_02.png)

# r
一番目と二番目のデータを入れ替えます。

```
3 2r
```
![b03_03.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc3/b03_03.png)

# s *x* , l *x*
一番上のデータを取り出し、s *x* で *x* という名前の変数に入れます。l *x* で *x* のデータをスタックの一番上に積みます。 *x* は一文字のものに限ります。数字でも正常に動きます。

```
1 2 3sXlXlX
```

![b03_04.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc3/b03_04.png)

# P
文字列をスタックに積むときは[*characters*]と書きます。
「P」はスタックの一番上の文字列を取り出し、改行を付けずに出力します。一番上が数値であればその数値が文字コードになる文字を出力します。数値が256以上であれば256進数に直して、文字を2文字以上出力します。

```
[cde]24930PP
```

|出力|abcde|
|:-:|:-|

![b03_05.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc3/b03_05.png)

$24930=97\times256+98$<br>で97はa、98はbなのでabを出力しています。

# R
一番上の数値nを取り出し、残ったスタックの上からn番目のデータを一番上に持ってきます。<br>一番上の数値が-n (n>0) の場合は一番上のデータを上からn番目になるように入れ替えます。

```
[f][e][d][c][b][a]4R
```

![b03_06.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc3/b03_06.png)

***

```
[f][e][d][c][b][a]0 4-R
```

![b03_07.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc3/b03_07.png)

nがデータの数よりも大きいときはnがデータの数と同じときのふるまいをします。

# 実際の問題
[ABC005](https://atcoder.jp/contests/abc005/tasks/abc005_1)

|入力|4 7|
|:-:|:-|

```
?r/p
```

|出力|1|
|:-:|:-|

![a005_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc3/a005_01.png)
***
[ABC012](https://atcoder.jp/contests/abc012/tasks/abc012_1)

|入力|1 2|
|:-:|:-|

```
?n[ ]Pp
```

|出力|2 1|
|:-:|:-|

![a012_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc3/a012_01.png)
空白の文字コードは32であるため、[ ]の部分は32としてもよい
***
[ABC014](https://atcoder.jp/contests/abc014/tasks/abc014_1)

|入力|7<br>3|
|:-:|:-|

```
??dd4Rr%-r%p
```

|出力|2|
|:-:|:-|

![a014_02.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc3/a014_02.png)

入力をa,bとします。「dd4Rr」でまずデータを意図した順に並べます。次に$b-a\%b$でいくつ買い足すかを求めますが、これだと買い足す必要がないときの答えが$b$になってしまうのでこれをbで割った余りにしています。

下はRのコマンドを知る前に私の書いたコードです。

|入力|7<br>3|
|:-:|:-|

```
?d1-?dsB/1+lB*r-p
```

|出力|2|
|:-:|:-|

![a014_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc3/a014_01.png)

入力をa,bとします。$a \leqq bn$を満たす最小のnを求めて$bn-a$を答えとしています。$bn=a$となる場合のために「1-」をしています。
