# [ABC053](https://atcoder.jp/contests/abc053/tasks/abc053_a)
<details>
<summary>[ARC][ABC]?C00>0rp</summary><div>

```
[ARC][ABC]?C00>0rp
```

|:-:|:-:|

|出力|ABC|
|:-:|:-:|

![a053_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc-a51-75/a053_01.png)

# [ABC055](https://atcoder.jp/contests/abc055/tasks/abc055_a)
<details>
<summary>?d4*rF/-200*p</summary><div>

```
?d4*rF/-200*p
```

|入力|20|
|:-:|:-:|

|出力|15800|
|:-:|:-:|

![a055_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc-a51-75/a055_01.png)

答えは$800N-200 \lfloor N/15 \rfloor$です。200でくくって$200(4N-\lfloor N/15 \rfloor)$として求めています。「F」は15と解釈されます。
</div></details>

# [ABC064](https://atcoder.jp/contests/abc064/tasks/abc064_a)
<details>
<summary>[NO][YES]0?r2*+r4*+4%=0rp</summary><div>

```
[NO][YES]0?r2*+r4*+4%=0rp
```

|入力|4 3 2|
|:-:|:-:|

|出力|YES|
|:-:|:-:|

![a064_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc-a51-75/a064_01.png)

***

|入力|2 3 4|
|:-:|:-:|

|出力|NO|
|:-:|:-:|

![a064_02.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc-a51-75/a064_02.png)

$100r+10g+b$を4で割った余りは、$4r+2g+b$を4で割った余りと同じです。$2g+b$を求めたあと、残っている$r$を4倍して足すことで$r$をスタックから消しています。
</div></details>

# [ABC070](https://atcoder.jp/contests/abc070/tasks/abc070_a)
<details>


|入力|575|
|:-:|:-:|

|出力|Yes|
|:-:|:-:|

![a070_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc-a51-75/a070_01.png)

|出力|No|
|:-:|:-:|
