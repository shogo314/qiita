# [ABC076](https://atcoder.jp/contests/abc076/tasks/abc076_a)
<details>
<summary>??2*r-p</summary><div>

```
??2*r-p
```

|入力|2002<br>2017|
|:-:|:-:|

|出力|2032|
|:-:|:-:|

![a076_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc-a76-100/a076_01.png)

$(R+x)/2=G$より、$x=2G-R$です。
</div></details>

# [ABC081](https://atcoder.jp/contests/abc081/tasks/abc081_a)
<details>
<summary>?9%p</summary><div>

```
?9%p
```

|入力|101|
|:-:|:-:|

|出力|2|
|:-:|:-:|

![a081_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc-a76-100/a081_01.png)

入力を数として読み込み、各桁の和を求めます。各桁の和を9で割った余りは、元の数を9で割った余りと同じです。各桁は0か1で和は3以下なので、9で割った余りがそのまま答えになります。
</div></details>

|:-:|:-:|

|出力|Even|
|:-:|:-:|

![a086_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc-a76-100/a086_01.png)

***

|入力|1 21|
|:-:|:-:|

|出力|Odd|
|:-:|:-:|

![a086_02.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc-a76-100/a086_02.png)
