# はじめに
前回までは、マクロを使ってif文のような処理を書いてきました。今回は、マクロの中で自分自身を実行することで、for文やwhile文のような繰り返しを書きます。

# マクロで繰り返す
dcにはfor文やwhile文はありませんが、マクロの最後で比較のコマンドを使い、条件を満たすときに同じマクロをもう一度実行すれば、繰り返しになります。

```
5[dp1-d0<a]dsax
```

|出力|5<br>4<br>3<br>2<br>1|
|:-:|:-|

「dsax」は、積んだマクロを「d」で2つにして、片方を「sa」でaに入れ、もう片方を「x」で実行します。「[ ]sa lax」と書くのと同じですが、1文字短くなります。

マクロの中では、「dp」で一番上の数を出力し、「1-」で1を引きます。「d0<a」は、一番上の0が二番目の数より小さいとき、つまり1を引いた数が正のときに、aをもう一度実行します。5から1まで出力して0になったところで、繰り返しが終わります。

<details><summary>何回まで繰り返せるか</summary><div>

マクロの最後で別のマクロを実行するときは、dcは実行中のマクロを終わらせてから次のマクロに移ります。そのため、このように最後で自分自身を実行する繰り返しは、回数が多くても問題なく動きます。マクロの途中で自分自身を実行すると、終わっていないマクロがたまっていき、繰り返すたびにメモリを使います。この記事の問題では最大で1万回ほど繰り返しますが、どれも最後で実行しているので、すぐに終わります。

</div></details>

# 決まった回数繰り返す
[ABC021](https://atcoder.jp/contests/abc021/tasks/abc021_a)

```
?p[1pr1-d0<a]dsax
```

|入力|3|
|:-:|:-|

|出力|3<br>1<br>1<br>1|
|:-:|:-|

![a021_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc7/a021_01.png)

1は2の累乗数なので、$N$を$1$を$N$個足したものと考えれば、個数の$N$と、1を$N$回出力すれば正解になります。
「?p」で$N$を読み込んで出力します。マクロの中では「1p」で1を出力し、「r」で残りの回数を一番上に持ってきて「1-」で1を引きます。「d0<a」で残りの回数が正なら繰り返します。出力した1はスタックに残っていきますが、答えには関係ありません。

# データの数を数える
前回少しだけ使った「z」は、スタックにあるデータの数を積むコマンドです。

```
1 2 3zp
```

|出力|3|
|:-:|:-|

繰り返しの中で値を積んでいくと、「z」で何回繰り返したかがわかります。ABC021は、次のようにも書けます。

```
?psN[1zlN>a]dsaxf
```

「?psN」で$N$を出力してから$N$に入れます。マクロでは1を積み、データの数が$N$より少ない間は繰り返します。「zlN>a」は、一番上の$N$が二番目のデータの数より大きいときにaを実行します。最後に「f」でスタックに積んだ$N$個の1をすべて出力します。

# 条件を満たすまで繰り返す
[ABC032](https://atcoder.jp/contests/abc032/tasks/abc032_a)

```
?sA?sB?1-[1+ddlA%rlB%+0!=a]dsaxp
```

|入力|2<br>3<br>8|
|:-:|:-|

|出力|12|
|:-:|:-|

$n$から1つずつ数を増やしていき、$a$と$b$の両方で割り切れたところで止めます。while文で書く処理です。
「?sA?sB?」で$a,b$をメモリに入れ、$n$を積みます。マクロの最初で1を足すので、「1-」で先に1を引いておきます。

マクロの中では「1+」で1を足したあと、「dd」で数を3つにします。「lA%」で$a$で割った余りを求め、「r」で下の数を一番上に持ってきて「lB%」で$b$で割った余りを求めます。「+」で2つの余りを足すと、両方とも割り切れるときだけ0になります。「0!=a」で0でなければ繰り返します。
繰り返しが終わると、両方で割り切れる数がスタックに残っているので「p」で出力します。

答えは$a$と$b$の最小公倍数の倍数なので、最大でも$n$から$a \times b \leqq 10000$回ほど繰り返せば見つかります。

# 入力を繰り返し読む
[ABC022](https://atcoder.jp/contests/abc022/tasks/abc022_a)

```
[lC1+sC]sb[dlT!<b]sc[0?--dlS!>clN1-dsN1<a]sa?sTsSsN?dlS!>clN1<alCp
```

|入力|5 50 100<br>120<br>-10<br>-20<br>-30<br>70|
|:-:|:-|

|出力|2|
|:-:|:-|

1日ずつ体重を計算して、$S$以上$T$以下の日を数えます。入力の行数が$N$で決まっているので、「?」を実行する回数を数えて、入力の終わりを越えて「?」を実行しないようにします。

この問題で難しいのは、変化量が負のときです。dcでは負の数は`_10`のように書くので、「?」で`-10`を読み込むと、「-」が引き算のコマンドとして実行され、そのあと10が積まれます。そこで、体重$X$だけがスタックにある状態で、「0?--」と書きます。

変化量が10のとき

![a022_01.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc7/a022_01.png)

変化量が-10のとき

![a022_02.png](https://raw.githubusercontent.com/shogo314/qiita/main/images/dc7/a022_02.png)

正のときは$X,0,10$が積まれるので、1つ目の「-」で$0-10=-10$、2つ目の「-」で$X-(-10)=X+10$になります。
負のときは、「?」の中の「-」で$X-0=X$になってから10が積まれるので、1つ目の「-」で$X-10$になります。2つ目の「-」はスタックにデータが1つしかないのでエラーになりますが、エラーメッセージが出るだけで、スタックは$X-10$のまま残ります。
どちらの場合も新しい体重が求まります。この方法は、スタックに体重以外のデータがないときにしか使えないので、日数や回数はすべてメモリに入れています。

それぞれのマクロは次のとおりです。

- bは、ベストボディーの日数$C$に1を足すマクロです。
- cは「dlT!<b」で、体重が$T$以下ならbを実行するマクロです。「!<b」は一番上の$T$が二番目の体重より小さくないときにbを実行します。
- aは、次の日の体重を読み込んで調べるマクロです。「0?--」で体重を更新し、「dlS!>c」で体重が$S$以上ならcを実行します。「!>c」は一番上の$S$が二番目の体重より大きくないときにcを実行します。「lN1-dsN1<a」で残りの日数$N$を1減らし、まだ1より大きければ繰り返します。

本体では「?sTsSsN」で$N,S,T$をメモリに入れ、「?」で1日目の体重$W$を読み込みます。1日目を「dlS!>c」で調べてから、$N$が1より大きければaを実行します（制約から$N \geqq 2$なので必ず実行されます）。最後に「lCp」で日数を出力します。何も入れていないメモリ$C$は0なので、最初に0を入れておく必要はありません。

aは2日目から$N$日目までの$N-1$回実行されるので、「?」は入力の行数と同じ$N+1$回だけ実行されます。[以前の記事](https://qiita.com/shogo314/items/1b4833f4b66ea8f599d3)で紹介したように、AtCoderのdcでは入力の終わりで「?」を実行するとプログラムが終了してしまうので、回数を合わせることが大切です。
